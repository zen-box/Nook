# 查看小组件内容与共享状态

在 iPhone 桌面添加 Nook 小组件时，可选日程、下一段行程、最近便签、纪念日倒计时或快捷入口。日程优先展示安排，任务仅显示待办数量。

设置 → 小组件提供“显示详情”“刷新小组件数据”和预览。详情默认关闭；开启后可以显示日程、行程和便签标题以及已填写的交通摘要。便签正文、附件、密码库和密钥不进入共享文件。

预览和扩展编译同一份布局。预览用本机数据，因此预览有内容只能说明记录和布局正常；桌面扩展还需要实际读取共享文件。

## 桌面一直没有数据时

1. 解锁并打开 Nook，在设置中刷新小组件数据。
2. 若显示“共享数据已更新”，查看桌面是否刷新。系统决定实际刷新时机；发布新数据会请求重新加载时间线，时间线也包含日程开始、结束和午夜节点。
3. 若显示共享权限不可用，检查重签配置：主 App 与 `NookWidgets.appex` 的签名和描述文件都必须允许 `group.com.nook.personal`。只保留扩展、只改 Bundle ID 或只写一个 entitlement 文本不能授予共享权限。
4. 若组件提示无法读取，先解锁后刷新；若持续出现，核对两端的 App Group 和重新签名安装。

小组件分别报告共享权限缺失、尚无共享数据和数据读取失败。空内容会显示“暂无行程 / 便签 / 纪念日”，不会再用“打开 Nook”掩盖所有状态。

当前自动检查包含共享文件读写 / 损坏状态、旧格式兼容、隐私投影，以及英文原生预览。重签后的描述文件、App Groups 权限和桌面刷新仍需在对应手机上检查。
