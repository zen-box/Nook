# 便签与提醒

## 连续便签

便签标题下是同一个 UITextView 编辑表面。文字、勾选清单和照片按正文顺序保存；工具条可设置标题 / 正文 / 粗体 / 斜体、切换当前行清单、在光标处添加照片。清单行回车添加下一项，空清单行回车退出。勾选圆圈切换完成状态，首页待办的勾选同时更新正文。照片可在正文中选中后删除，编辑期间撤销能恢复照片。

数据使用可移植的 `NoteRun` 数组保留顺序、样式、清单 ID 和附件引用；`body`、`todos`、`file_refs` 同步保存为搜索 / 列表 / 首页 / 文件清理的投影。SQLite 新增 `v3-note-content` 迁移，旧记录的 `rich_content` 为 NULL，首次编辑时保留原正文、清单和照片。JSON 备份保留新正文和旧字段；仍不包含照片文件本身。

## 当前提醒规则

- 定时日程：编辑页选择提醒提前量；新建默认提前 10 分钟，可选无、准时、5 / 10 / 15 / 30 分钟、1 / 2 小时或 1 天。
- 触发时间 = 日程开始时间 − 提前量。触发时间已过去就跳过，即使日程尚未开始也不补发。
- 全天日程：当前不发送通知；切换为全天时，保存的提前量为 nil。
- 行程：日期范围与日程归组，本身不发送通知；给行程内的具体日程设置时间与提前量。
- 纪念日：当前只显示倒计时，不发送系统通知。
- 通知在本机由 UserNotifications 调度，不需要 Go 服务端；需要在 iOS 设置中允许 Nook 通知。当前未配置前台横幅展示代理，测试时将 App 切到后台。专注模式、静音、系统通知显示设置由 iOS 控制。
- 创建 / 修改 / 删除日程、App 启动、备份恢复时重建提醒，仅保留最近的 60 条未来提醒。超过 60 条后需在后续打开 App 或更新日程时补排。
- 首页铃铛当前展示今日尚未结束的日程，是 App 内的今日安排列表，不是已投递系统通知的历史，也不代表其中每条都启用了通知。

## 本版检查

Windows 核心包测试覆盖旧便签兼容、正文混排顺序、检索与首页清单投影、JSON 备份往返。`ios/NookTests/NoteEditorTests.swift` 增加原生富文本编解码、数据库 v2 升 v3、关闭连接重开、首页勾选同步，以及照片撤销期间文件保留检查；这些需在 Codemagic 的 `ios-tests` 工作流执行。

最新 IPA 的真机检查：

1. 保持设置面板打开，浅色 → 深色 → 跟随系统，背景、文字和工具条立即跟随。
2. 用主密码解锁一次，启用快捷解锁，锁定后点击 Face ID；认证成功可打开，取消后保持锁定，错误信息可见。重签权限受限时用主密码继续。
3. 新建便签输入中文与 emoji，混排文字、两项清单和两张照片；勾选、回车续项、空行退出、选中文本改格式，撤销 / 重做，再重启确认内容和顺序。
4. 从旧数据升级，原正文、清单、照片仍存在；删除便签后返回不应复活。
5. 新建几分钟后的日程并选择准时提醒，允许通知后切到后台，检查本地通知；无提醒与全天日程不通知。

完整 iOS 类型检查、原生渲染、键盘交互、Face ID 和重签钥匙串访问仍以云端构建及本版 IPA 的真机结果为准。
