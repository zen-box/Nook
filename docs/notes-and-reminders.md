# 便签与提醒

## 连续便签

便签标题下是同一个 UITextView 编辑表面。文字、清单、照片和录音按正文顺序保存；工具条可设置标题 / 正文 / 粗体 / 斜体，切换清单，在光标处添加照片和录音。清单回车续项、空清单回车退出，勾选同时更新列表投影。录音可播放、删除、使用本机 Speech 转写；撤销 / 重做保留附件引用。

`NoteRun` 保存顺序、样式、清单 ID 和附件引用；`body`、`todos`、`file_refs` 为搜索 / 列表 / 首页 / 文件清理投影。SQLite v3 兼容旧正文，v4 加入独立任务等功能。未编辑的旧记录继续可读，首次编辑保留其正文、清单与照片。

本机识别不支持时提示继续手输，不上传录音兜底。录音 AAC、64 kbps、最长 1 小时；保存音频上限 90 MiB。麦克风和 Speech 权限按需申请。系统照片选择器不需要完整相册权限。

旧 JSON 只含附件引用，完整照片 / 录音需使用 `.nookbackup` 或设备迁移。

## 提醒规则

- 定时日程：触发时刻为开始时间减提前量；过期触发点不补发。交通信息进入通知详情。
- 全天日程：编辑器不提供定时提醒，切换全天时清空提前量。
- 行程：分组本身不通知；车次 / 航班等具体日程设置出发时间与提醒。
- 独立任务：到期时间减提前量；完成后不再排程。
- 纪念日：可设当天 / 提前若干天、当地小时与分钟；每年或单次，2 月 29 日按公历规则回退。
- 每日 / 每周无限规则满足无例外等条件后使用系统原生重复请求，其余日程滚动展开，向前最多 2 年；纪念日保留后续若干年候选。
- 所有来源合并排序后保留最早 60 个请求。超过后需打开 App 或修改数据补排，不能承诺长期不打开仍覆盖全部复杂规则。
- 首次存在待调度提醒时申请通知权限。App 启动、业务修改及恢复后重排；拒绝权限会反馈并提供系统设置入口。
- 前台通过代理展示通知，后台或 App 关闭后由 iOS 处理已排入系统的请求，无需 Go 服务端。专注模式和系统通知设置影响实际呈现。
- 首页铃铛展示 App 内今日安排，不是已投递通知历史。

## 重复和编辑

日程支持日 / 周 / 月 / 年、间隔、星期、结束日期或次数，保留时区。修改 / 删除选择仅本次、本次及以后、整个系列。编辑整系列只传播实际改变字段，保留其他例外差异。Agent 对同一规则执行相同校验，不绕过原生编辑行为。

## 真机验收

1. 设置面板保持打开，浅色 / 深色 / 系统切换立即更新。
2. 混排中文、emoji、清单、照片与录音；编辑、撤销、重启，内容及顺序完整。
3. 录音播放 / 本机转写，拒绝权限后文字功能仍可用；不支持本机识别时提示清楚。
4. 创建几分钟后日程和任务、设置临近纪念日，检查前台横幅及关闭 App 后通知。
5. 创建每周一固定时刻日程，修改单次 / 后续 / 整系列，重启后查看规则、例外和提醒。
6. 填火车站 / 车次 / 车厢 / 座位及航班信息，检查列表、详情和通知；不期待实时外部信息。

自动检查位置为 NookCore 测试、`NoteEditorTests`、`AssistantSafetyTests` 与 UI 测试。真实麦克风、通知、硬件认证及重签行为以设备验收为准。
